WAR: THE LONG MARCH - YOUR ART
==============================

Every picture in the game lives in this folder. To use your own art, draw a new picture and save it
over the old file with EXACTLY the same name (PNG). The game picks it up next time it loads.

- Square pictures work best for icons (the ones here are 128 x 128). Any size is fine; they are scaled to fit.
- Transparent backgrounds look best.
- Your pictures are shown as you drew them (no cyan tint).
- If a file is missing or broken, the game shows its built-in icon instead, so nothing breaks.
- card-back\card-back.png is the back of every card (330 x 480 here; it is stretched to the card shape).
- The playing cards themselves (hearts, clubs, spades, diamonds) are in ..\sprites\cards\.

After changing art for the PC exe, ask Claude to rebuild it (the exe carries a copy of this folder).
The phone version gets the new art when Claude publishes it.
